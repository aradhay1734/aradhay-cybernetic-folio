# Aradhay Sharda Portfolio

## Overview
Build a polished, responsive personal portfolio for Aradhay Sharda that presents him as a Computer Science student and aspiring cybersecurity professional. The site will use a dark navy, cyan-accented visual system with restrained network and terminal details, avoiding gaming or stereotypical “hacker” styling.

## Pages and navigation
- Create separate pages for Home, About, Skills, Experience, Projects, Education, Career Goals, and Contact.
- Add a shared sticky navigation bar with active states, a mobile menu, and a prominent “Explore My Work” action.
- Include a “Resume coming soon” treatment that can become a download link when the CV is supplied.

## Content and interactions
- Home: name, requested subtitle and introduction, current UNB status, two primary actions, profile-photo placeholder, and subtle animated network/grid artwork.
- About: degree and 2029 graduation date, cybersecurity interests, learning mindset, transferable retail skills, and chess-derived strengths.
- Skills: clearly grouped technical, cybersecurity, professional, and learning-focused capabilities without overstating experience.
- Experience: recruiter-friendly presentation of retail/customer-service experience using honest placeholder labels where employer details were not provided.
- Projects: interactive project cards framed as current learning work or project concepts, avoiding fabricated completed achievements.
- Education: UNB degree timeline and relevant study focus.
- Career Goals: near-term learning goals and long-term cybersecurity direction.
- Contact: clear email/contact placeholders and professional network links that can be replaced with real details.

## Visual system
- Define semantic colors, typography, borders, glows, shadows, and animation tokens in the global design system.
- Use near-black/navy surfaces, blue and cyan accents, crisp sans-serif typography, fine grid lines, subtle glass panels, and restrained glow.
- Add smooth page transitions, hover feedback, a small typing-style terminal detail, and reduced-motion support.
- Keep all content readable and well-spaced across desktop, tablet, and mobile.

## Technical details
- Use TanStack Router pages and shared React components.
- Add unique metadata for every page, including title, description, Open Graph, and Twitter card tags.
- Use accessible landmarks, keyboard-friendly controls, one H1 per page, descriptive labels, and a CSS-created photo placeholder that is easy to replace later.
- Verify the finished site in desktop and mobile browser sizes, including menu behavior and every navigation destination.
